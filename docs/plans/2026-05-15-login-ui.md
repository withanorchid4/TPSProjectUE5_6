# Login UI Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add Login and Character Select UI so players can enter account/password, see their characters, and double-click to enter the game.

**Architecture:** Replace the auto-login flow with two UMG Widget Blueprints controlled by Python. MainMenu shows WBP_Login → on success shows WBP_CharSelect → double-click character → LoadLevel. NetworkManager splits connect_and_login() into separate connect/login/register methods called by UI. Existing reconnect logic stays unchanged.

**Tech Stack:** NePy + UMG Widget Blueprints + Python (PyUserWidget pattern from UMGWithPy sample)

### Task 1: Modify NetworkManager — split auto-login into step-by-step API

**Files:**
- Modify: `Content/Scripts/network/network_manager.py`

**Changes:**
1. Remove `connect_and_login()` auto-flow (keep it as a backward-compat method but deprecated)
2. Add `connect(host, port)` — just establish TCP connection
3. Add `login(account, password)` — send CsLogin with is_register=False
4. Add `register(account, password)` — send CsLogin with is_register=True
5. Add `select_character(char_id)` — send CsSelectCharacter
6. Add `create_character(char_name)` — send CsCreateCharacter
7. Add `get_characters()` — send CsGetCharacters
8. Add new callbacks: `on_login_result(success, msg)`, `on_register_result(success, msg)`, `on_character_list(chars)`, `on_create_result(success, char_info)`, `on_enter_game(player_id)`, `on_reconnect(player_id, location)`
9. Remove DEFAULT_ACCOUNT / DEFAULT_PASSWORD
10. Keep `_on_reconnect` and all existing game callbacks unchanged

**Key design:** Each callback fires with parsed data (dicts, not raw protobuf), so UI doesn't need to know about protobuf.

**Step 1:** Write the modified NetworkManager

**Step 2:** Test by running the existing test_quick_listen.py (should still work since we keep connect_and_login for backward compat)

**Python Controller (login_ui.py):**
```python
class LoginPanel(PyUserWidget):
    UMG_PATH = 'Panels.UMG_Login'
    
    def construct(self):
        self.btn_login.BindEvent('OnClicked', self.on_login)
        self.btn_register.BindEvent('OnClicked', self.on_register)
    
    def init(self, net_manager):
        self._nm = net_manager
        self._nm.on_login_result = self._on_login_result
        self._nm.on_register_result = self._on_register_result
    
    def on_login(self):
        account = self.etb_account.GetText()
        password = self.etb_password.GetText()
        if not account or not password:
            self.txt_status.SetText("Please enter account and password")
            return
        self.txt_status.SetText("Logging in...")
        self._nm.login(account, password)
    
    def on_register(self):
        account = self.etb_account.GetText()
        password = self.etb_password.GetText()
        if not account or not password:
            self.txt_status.SetText("Please enter account and password")
            return
        self.txt_status.SetText("Registering...")
        self._nm.register(account, password)
    
    def _on_login_result(self, success, msg):
        if success:
            self.txt_status.SetText("Login success!")
            # Transition to char select
        else:
            self.txt_status.SetText(f"Login failed: {msg}")
    
    def _on_register_result(self, success, msg):
        if success:
            self.txt_status.SetText("Register success! Logging in...")
            account = self.etb_account.GetText()
            password = self.etb_password.GetText()
            self._nm.login(account, password)
        else:
            self.txt_status.SetText(f"Register failed: {msg}")
    
    def destruct(self):
        self.btn_login.UnbindEvent('OnClicked', self.on_login)
        self.btn_register.UnbindEvent('OnClicked', self.on_register)
        super().destruct()
```

**User must do in UE Editor:**
1. Create Widget Blueprint `WBP_Login`
2. Add widgets with the names above (etb_account, etb_password, btn_login, btn_register, txt_status)
3. Set the Python class in the widget's details panel
