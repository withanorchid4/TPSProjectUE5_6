# TPS 游戏操作说明

## 一、服务端启动

### 环境要求
- Python 3.10+
- protobuf 库：`pip install protobuf grpcio-tools`

### 启动方式
双击 `server.bat` 或在 `server/` 目录下执行：
```
python main.py
```

服务器默认监听 `0.0.0.0:9999`，按 Ctrl+C 停止。

## 二、客户端操作

### 基础移动
| 按键 | 功能 |
|------|------|
| W/A/S/D | 前后左右移动 |
| 空格 | 跳跃 |
| Shift(按住) | 冲刺 |

### 视角控制
| 按键 | 功能 |
|------|------|
| 鼠标移动 | 转动视角 |
| 鼠标右键(按住) | 瞄准模式（拉近摄像机） |

### 武器系统
| 按键 | 功能 |
|------|------|
| 鼠标左键 | 射击 |
| R | 换弹 |
| T | 切换点射/连射模式 |
| E | 切换持枪/收枪 |
| Q | 发射魔法箭（晕眩范围内敌人3秒） |

### 其他
| 按键 | 功能 |
|------|------|
| B | 给自己添加增攻Buff |

## 三、游戏流程

1. **启动服务端** — 先运行 `server.bat`
2. **启动客户端** — 在 UE 编辑器中 Play 或运行打包版
3. **登录界面** — 输入账号密码，点击"登录"或"注册"
4. **角色选择** — 选择已有角色或创建新角色，点击"进入游戏"
5. **游戏中** — 击杀所有敌人即可通关
6. **关卡切换** — Level1 通关后自动进入 Level2
7. **断线重连** — 游戏中断线后，5分钟内用同一账号重新登录可回到战场

---

## 四、网络协议

- 传输层：TCP
- 端口：9999
- 序列化：Google Protocol Buffers
- 包格式：`[4字节大端长度][2字节大端msg_id][protobuf body]`

---

## 五、服务端架构

- 单线程 select 事件循环（~30fps）
- 数据库：sqlite3（账号、角色持久化）
- 断线重连：5分钟内重连恢复战场状态
